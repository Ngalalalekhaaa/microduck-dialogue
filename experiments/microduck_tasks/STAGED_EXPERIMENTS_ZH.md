### Q0：完整监督、梯度与显存预检

Q0 从冻结训练集确定 32 条共同域样本，固定 seed17，只按训练数据与长度选取，不按开发预测选题。
包含 12 个单目标、6 个三目标、6 个六目标、8 个无目标回合；decision 为 20 replace、4 append、
4 decline、2 clarify、2 cancel。含全部 1200 条中输入加答案最长的样本，ID 和内容哈希见 `q0/data/manifest.json`。
本次是同一小集合训练前后检查，不是开发准确率或泛化实验；480 条盲测保持封存。

使用实际 processor 对全部 1200 train / 240 dev 做完整输入加答案长度预检，范围分别为 2725–3042 / 2723–3064 token。
输入采用同一 P6 渲染和非思考生成前缀；当前 JSON 答案与 EOS 完整监督，其余输入与历史示例全部 mask。
未删样本、未截断；上限 4096，按原 FLA 固定桶方式右补齐到 1024 的倍数，本批实际为 3072。
只计算每个答案 token 对应前一位置的 logits，覆盖完整答案，不是只保留末一个位置。
针对性测试验证该损失及 logits 梯度与完整序列移位、mask 后的交叉熵完全一致；3 项 Q0 检查通过，Ruff 通过。

本次使用本地明确监督边界的 PEFT 训练循环，没有直接运行参考 ms-swift 脚本。PEFT 0.19.1 安装在独立
`.cache/microduck_head/qlora_deps` 覆盖目录，未升级现有 torch/transformers/仿真依赖。
量化仍为原固定 Qwen 的 NF4 双重量化；仅语言层全部线性层注入 rank8/alpha16/dropout0.05 LoRA，
实际 8,409,600 个可训练参数，包含普通注意力、线性注意力和 MLP；视觉、词嵌入及输出层冻结。
采用 BF16 autocast，LoRA 与归一化参数为 FP32；大型冻结浮点权重保留 BF16。
配置依据 [PEFT 固定版本量化训练说明](https://huggingface.co/docs/peft/v0.19.0/developer_guides/quantization)，
实际模块列表、精度策略和本机检查见 `q0/probe/model_preflight.json`，不能只凭文档推断本机可训练。

两个最长样本已完成前向、反向与一次 optimizer 更新。最长 3042 token，其中 144 个答案 token 完整参与损失；
LoRA 梯度有限且非零，更新前后权重哈希不同，预检后恢复原始适配器，预检更新不混入正式 Q0。
训练步峰值 allocated 2824.42 MiB；模型准备瞬时峰值 3775.70 MiB，二者不含桌面/驱动进程。
首次包含编译的微批次约 37.5 秒，第二次约 3.0 秒。详细数据见 `q0/probe/smoke.json`。

Q0 运行顺序：同 32 条贪心自由生成 → 100 次更新（batch1、累积8，共800微批次）→ 同集合自由生成 →
全新加载基座及保存的适配器复核 3 条输出。lr=1e-4，5 次更新 warmup，cosine，weight_decay=.01，clip=1；
第50/100次保存适配器，使用最后100次版本，不用开发集挑 checkpoint。

## 产品语义与历史实验版本

按最新需求，当前在线能力快照改为 `max_goals: 15`：单次计划最多15项，追加后的 `active + pending + 新增` 未完成目标总数也最多15。合法计划保留完整顺序；16项或累计超限整组拒绝，不截断。输入、输出 Schema、上下文校验及提示词采用同一容量。旧显式 `max_goals: null` 仅保留为历史接口兼容，旧正整数快照仍按其明确容量校验。

下面表格记录的是此前 P/H/Q0/Q1 冻结实验的旧规则。旧数据、分数、模型和封存盲测不回写、不重标；Q1 旧六目标训练权重未因本次容量与暂停规则更新而重新训练，也不把旧结果当作新协议成绩。当前开发用例生成器为 `microduck-dev240-v3-cap15`，覆盖15项接受、16项拒绝及追加总数边界；7项以上完整计划仍超出旧六步小头的共同域。新数据不可直接套用旧 Q1 的 common236、非动作样本数和选择门槛，后续训练与评测须独立记录。

当前安全暂停支持有限目标：完成整个动作及稳定恢复后，再挂起未执行的剩余队列；持续行走在短段边界收稳后保留当前目标。恢复不重演已经完成的动作，全部完成后为空闲。推理期间的暂停不打断推理，新计划完整保留为暂停状态，不先执行第一项。停止／取消另走即时锁存路径，撤销当前任务、清空队列并拒绝停止前的迟到计划；已取消任务不能恢复。

| 无限移动之后还有目标 | 澄清或拒绝，协议拒绝不可到达的后缀 |
| 暂停与恢复（旧规则） | 旧冻结实验只对持续行走开放；当前安全暂停扩展见上文，取消仍不等于暂停 |
